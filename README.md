# Aromas – Handmade Ocean-Inspired Candles

A premium, modern, and responsive static website for **Aromas by Anu**, featuring handmade scented candles and concrete jars inspired by the calm of the ocean.

## Features
- **Ocean Theme Design**: Sleek dark and sandy ocean color palette using CSS variables.
- **WhatsApp Integration**: Allows direct ordering of products, pre-filled WhatsApp link generation, and a floating WhatsApp CTA.
- **Interactive Forms**: A "Ready to Bring the Ocean Home?" message form on the homepage and contact page that generates ready-to-send messages directly to WhatsApp.
- **Fully Responsive**: Works seamlessly on mobile, tablet, and desktop viewports.
- **Lightweight & Fast**: Built purely with semantic HTML5, custom Vanilla CSS, and modern JS.

## Project Structure
- `index.html` - The home page featuring bestsellers, testimonial section, and the main contact form.
- `collection.html` - The product catalog with dedicated order buttons.
- `about.html` - Information about the craft, values, and story of Aromas by Anu.
- `contact.html` - Contact details and contact form.
- `styles.css` - Custom styling using a robust design system.
- `script.js` - Dynamic interactions, responsive navbar menu toggle, and WhatsApp form message parser.
